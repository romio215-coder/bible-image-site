# 남은 연결 및 운영 작업

## 외부 서비스가 준비되어야 진행할 작업

- Supabase: 사용자 소유 프로젝트의 URL·공개 키, 로그인 방식과 배포 도메인이 필요합니다. 현재 SQL/RLS와 환경변수 예시는 준비되어 있지만 Auth UI·세션·실제 동기화 어댑터는 구현하지 않았습니다.
- 공개 배포: 호스팅과 도메인이 필요합니다. Docker/Node 배포 준비와 GitHub 검증 워크플로는 포함되어 있습니다.
- 운영 안내: 운영 주체·문의 주소·실제 개인정보 처리 방식이 정해져야 공개 이용약관과 개인정보처리방침을 확정할 수 있습니다. 현재 `/about`은 비회원 기기 저장 방식을 설명합니다.
- 실제 iPhone Safari의 설치·파일 공유 확인: 현재 모바일 검증은 Edge 에뮬레이션입니다.

## 현재 범위

인물은 대표 이야기 12개, 사건은 12개를 제공합니다. 연대표는 같은 사건의 본문 읽기 순서이며 역사적 연도 확정이나 성경 전체 사건 사전을 뜻하지 않습니다. 요약 옆에 원문을 표시하고 장절 링크로 연결합니다.

전체 성경 데이터와 비회원 읽기·검색·기록·카드·백업 기능은 사용할 수 있습니다. 배경은 자연 이미지 한 장과 일러스트 200종, 색상 3종입니다. 오프라인 읽기는 마지막으로 읽은 한 장을 지원합니다.
